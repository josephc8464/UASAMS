# UArizona Scholarship Application Management System (UASAMS)

A software platform developed for the University of Arizona College of Engineering (SFWE 301) to streamline, automate, and manage the scholarship application and award disbursement lifecycle.

## Tech Stack

* **Backend:** Java / Spring Boot
* **Frontend:** React (Planned) or Thymeleaf (Server-Side)
* **Build Tool:** Maven / Gradle

## Primary Subsystems

* **Front End:** Web interfaces tailored for Applicants, Donors/Sponsors, ENGR Administrators, and College Staff[cite: 1].
* **Back End:** Data management for applicant records and scholarship databases, integrated with a search engine[cite: 1].
* **Matching Engine:** Algorithmic matching of applicant qualifications against scholarship criteria with committee review controls[cite: 1].
* **Reports Engine:** Automated generation of candidate demographics, evaluation summaries, and disbursement tracking[cite: 1].

## Core Capabilities

* **Student Portal:** Complete online applications, upload supporting documents (transcripts, essays, recommendations), and track application status[cite: 1].
* **Donor Management:** Tools for donors and sponsors to create custom scholarships, define eligibility criteria, and track funding[cite: 1].
* **Automated Pre-Screening:** Pre-screens applications to filter out candidates who do not meet basic requirements before panel review[cite: 1].
* **Notifications System:** Automated email alerts and notifications for upcoming deadlines, status updates, and award decisions[cite: 1].
* **Access Control & Security:** Role-based permissions and FERPA-compliant access managed via administrator approval workflows[cite: 1].
